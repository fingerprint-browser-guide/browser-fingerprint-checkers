## Freeze recommendation

After publishing this package and updating Repository About/Topics/Social Preview, avoid frequent cosmetic README changes.
Future changes should be driven by:
1. tool availability/status changes;
2. material capability changes;
3. source/evidence updates;
4. new genuinely distinct detection layers.
